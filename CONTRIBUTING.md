# Contributing

Contributions that improve safety, clarity, or testing are welcome. Discuss large policy changes first. Keep changes narrow, include tests, and explain whether failure is open or closed.

Never submit real addresses, device or account identifiers, bucket names, keys, certificates, browsing records, or family-specific policy. Use reserved example domains and TEST-NET addresses.

```sh
OPENBLAS_NUM_THREADS=1 python -m pytest -q tests
```
